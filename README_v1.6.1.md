# FIXIS PRO v1.6.1
Customer Onboarding + Marketplace Client Foundation.

Instalación:
1. Migration 013 debe estar aplicada/validada.
2. Sustituir `lib/` por la versión incluida.
3. `flutter clean`
4. `flutter pub get`
5. `flutter analyze`
6. `flutter run`

Prueba recomendada: crear un correo cliente NUEVO para no mezclar perfiles profesionales existentes.
