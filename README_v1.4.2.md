# FIXIS PRO v1.4.2

Parche visual sobre v1.4.1.

## Instalación
1. Respaldar `lib` actual.
2. Copiar `fixis_v1_4_2/lib/` sobre el `lib/` del proyecto.
3. Copiar los archivos de `docs/` a la carpeta `docs/` del proyecto.
4. Ejecutar:

```bash
flutter clean
flutter pub get
flutter analyze
flutter run
```

## Supabase
No requiere migraciones SQL.
